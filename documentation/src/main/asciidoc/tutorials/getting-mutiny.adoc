== Using Mutiny in a Java application

Add the _dependency_ to your project using your preferred build tool:

[.tabs]
====

Apache Maven::
+
--

[source,xml,subs="attributes+"]
----
<dependency>
    <groupId>io.smallrye.reactive</groupId>
    <artifactId>mutiny</artifactId>
    <version>{versions-mutiny}</version>
</dependency>
----

--

Gradle (Groovy)::
+
--

[source,groovy,subs="attributes+"]
----
implementation 'io.smallrye.reactive:mutiny:{versions-mutiny}'
----

--

Gradle (Kotlin)::
+
--

[source,kotlin,subs="attributes+"]
----
implementation("io.smallrye.reactive:mutiny:{versions-mutiny}")
----

--

JBang::
+
--

[source,java,subs="attributes+"]
----
//DEPS io.smallrye.reactive:mutiny:{versions-mutiny}
----

--

====

== Using Mutiny with Quarkus

Most of the https://quarkus.io[Quarkus] extensions with reactive capabilities already depend on Mutiny.

You can also add the `quarkus-mutiny` dependency explicitly from the command-line:

[source,bash]
----
mvn quarkus:add-extension -Dextensions=mutiny
----

or by editing the `pom.xml` file and adding:

[source,xml]
----
<dependency>
  <groupId>io.quarkus</groupId>
  <artifactId>quarkus-mutiny</artifactId>
</dependency>
----

== Using Mutiny with Vert.x

Most of the https://vertx.io[Eclipse Vert.x] stack modules are available through the https://smallrye.io/smallrye-mutiny-vertx-bindings/[SmallRye Mutiny Vert.x Bindings] project.

Bindings for Vert.x modules are named by prepending `smallrye-mutiny-`.
As an example here's how to add a dependency to the `vertx-core` Mutiny bindings:

[.tabs]
====

Apache Maven::
+
--

[source,xml,subs="attributes+"]
----
<dependency>
    <groupId>io.smallrye.reactive</groupId>
    <artifactId>smallrye-mutiny-vertx-core</artifactId>
    <version>{versions-vertx-bindings}</version>
</dependency>
----

--

Gradle (Groovy)::
+
--

[source,groovy,subs="attributes+"]
----
implementation 'io.smallrye.reactive:smallrye-mutiny-vertx-core:{versions-vertx-bindings}'
----

--

Gradle (Kotlin)::
+
--

[source,kotlin,subs="attributes+"]
----
implementation("io.smallrye.reactive:smallrye-mutiny-vertx-core:{versions-vertx-bindings}")
----

--

JBang::
+
--

[source,java,subs="attributes+"]
----
//DEPS io.smallrye.reactive:smallrye-mutiny-vertx-core:{versions-vertx-bindings}
----

--
